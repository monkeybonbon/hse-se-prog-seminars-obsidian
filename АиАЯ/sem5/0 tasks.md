# 1 (1 б)

```c
char c[9];
int a[] = {1, 2, 3, 4, 5};
int *p = &a[1], i = 3;
char *q = c;
```

> **Примечание**
> Разность указателей имеет тип `ptrdiff_t`

| Выражение   | Значение | Тип | Побочный эффект |
| ----------- | -------- | --- | --------------- |
| `i++`       |          |     |                 |
| `++i`       |          |     |                 |
| `a[i]--`    |          |     |                 |
| `*p++`      |          |     |                 |
| `++*p`      |          |     |                 |
| `*++p`      |          |     |                 |
| `p - a`     |          |     |                 |
| `&c[8] - q` |          |     |                 |
| `a - q`     |          |     |                 |

