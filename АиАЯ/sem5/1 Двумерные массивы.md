Массивы могут содержать в себе другие массивы. При этом каждый внутренний массив должен быть одного размера с остальными
```c
int a[N][M] // N строк, M столбцов
```
![[Pasted image 20261117083744.png]]
> Каждый элемент всё так же последовательно будет лежать в памяти

Обращение к элементам делается посредством двойной индексации
```c
a[i][j] // *(*(a + i) + j))
```

```c
#include <stdio.h>
int main(void) {
	int a[5][6] = {
		{1, 2, 3, 4, 5, 6},
		{1, 2, 3, 4, 5, 6},
		{1, 2, 3, 4, 5, 6},
		{1, 2, 3, 4, 5, 6},
		{1, 2, 3, 4, 5, 6},
	}; // Массив из 5 массивов размера 6
	
	for (int i = 0; i < 5; i++) {
		for (int j = 0; j < 6; j++) {
			printf("%p ", &(a[i][j]));
			a[i][j] = i * 6 + j;
		}
		printf("\n");
	}
	
	for (int i = 0; i < 5; i++) {
		for (int j = 0; j < 6; j++) {
			printf("%d\t", a[i][j]);
		}
		printf("\n");
	}
	return 0;
}
```

> Очевидно, можно делать и более многомерные массивы
