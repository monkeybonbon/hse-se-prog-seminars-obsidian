# VLA массивы

В стандарте C99 есть возможность задавать размер массива **во время исполнения программы**, а не на этапе компиляции. При этом такой массив всё так же хранится на **стеке** (в отличие от динамических массивов, которые мы пройдем позже)

Такие массивы называются **Variable-Length Arrays (VLA)**

> В C++ такой фичи нет

Это позволяет нам задавать меняющийся от запуска к запуску размер, например после ввода переменной размера через `scanf`

```c
int main(void) {
	int n;
	scanf("%d", &n);
	
	int a[n]; // память выделится ВО ВРЕМЯ ИСПОЛНЕНИЯ
	
	for(int i = 0; i < n; i++) {
		scanf("%d", &a[i]);
	}
	
	return 0;
}
```

**Риски:**
- Переполнение стека при очень большом N - программа упадет на этапе Runtime, а не компиляции. А если и не упадет, то вызовет UB, так как перезатрет соседние переменные
- Небезопасно - Если пользователь введет некорректный размер (например, -5), получим UB и/или падение
- `sizeof` вычисляется во время исполнения (тогда как для обычных - во время компиляции)

> Можно использовать, если гарантированно введется небольшое значение, которое будет известно только во время исполнения программы

```c
#include <stdio.h>
int main(void) {
	int n;
	scanf("%d", &n);
	
	int a[n];

    for (int i = -n; i < 2 * n; i++) {
        printf("a[%d] \t %x \t %d\n", i, &a[i], a[i]);
    }
	
	return 0;
}
```
